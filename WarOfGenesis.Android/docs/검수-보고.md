## 진검수 — PC 판과 맞대어 조용히 빠진 것

| 살핀 것 | 결과 |
|---|---|
| 링크 안 한 원본 파일(Program · Win32 · Updater · EditorLauncher · BugReport · MyBugReportsDialog · HiResBackdrop · OriginalGameSetup · MediaFoundationAudio · DirectShowVideo · PlatformInfo · WaveOutPlayer) | Program 이 하는 일(원본 자리 차리기 · 그림 예제 · 터짐 기록)은 GameActivity 가 한다. 나머지는 뺀 기능이거나 대용품 |
| 정적 훅(시작 코드가 거는 것) | Program.Main 에 정적 대입 없음 — 빠진 것 없음 |
| 대용 함수 가운데 게임이 부르는 것 | 커서 그림(SetCursor · CreateIconIndirect)은 빈 함수 — 터치에는 커서가 없고, 패드는 원본이 커서를 숨기고 테두리로 보인다(menu-53). 문제 없음 |
| Process.Start(폴더 열기 · 주소 열기 · 다시 켜기) | 유닉스에서 Win32Exception — 원본이 모두 잡는다(터지지 않음, 알림만) |
| 통계 보내기 동의 창 | 주소 파일(stats-url.txt)을 싣지 않아 뜨지 않는다 |
| 설정 저장 | settings.json 등이 SD카드 자료 폴더에 쓰인다 |

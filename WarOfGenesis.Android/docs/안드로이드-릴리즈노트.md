# 안드로이드판 릴리즈 노트

<!-- CI(android.yml)가 태그 이름(## android-vX.Y.Z)의 대목만 떼어 Releases 설명으로 쓴다. 새 판은 맨 위에 적는다. -->

## android-v0.1.0

창세기전3 리메이크(원작 PC 판 v1.1.4)를 안드로이드에서 돌리는 첫 판입니다.

**원본 게임 자료는 들어 있지 않습니다.** 갖고 계신 창세기전3 파트1 · 파트2 설치 폴더를 폰(내장 저장소나 SD카드)에 넣고 앱에서 그 폴더를 골라야 합니다.

### 설치 · 처음 켜기
1. 아래 `WarOfGenesis-0.1.0.apk` 를 받아 설치합니다(출처를 알 수 없는 앱 허용이 필요할 수 있습니다).
2. 앱을 켜면 「모든 파일 접근」을 허용해 주세요(원본 폴더를 읽고 세이브를 쓰려고).
3. 「폴더 고르기」로 파트1 · 파트2 폴더가 들어 있는 폴더를 고릅니다 — 폴더 이름이 조금 달라도 안의 파일로 알아봅니다.
4. 「게임 시작」. 다음부터는 곧장 게임이 켜집니다(다시 고르려면 시스템 메뉴 > 도구 > 「원본 폴더 다시 고르기」).

### 되는 것
- 파트1 · 파트2 이야기 · 전투 · 저장/불러오기, 파트2 오프닝(모드 > 엔딩 영상) · 파트1 엔딩 영상
- 터치: 탭 = 클릭, 길게 누르기 = 오른쪽 클릭, 두 손가락 = 휠 · 오른쪽 클릭, 맵 끌기
- 게임 패드(레트로이드 같은 휴대용 기기 포함): PC 판 패드 조작 그대로. 패드가 없을 때만 화면 양옆에 단축 아이콘
- 화면비는 게임 설정 > 화면 > 해상도로, 남는 검은 여백은 설정 > 화면 > 「배경 그림」으로 채울 수 있습니다
- 다른 앱에 잠깐 다녀와도 게임이 이어집니다(알림줄에 「창세기전3 실행 중」). 최근 앱 목록에서 밀어 닫으면 완전히 꺼집니다

### PC 판과 다른 점
- 뺀 것: 자동 업데이트 · 버그 리포트 · 편집기 · 고해상도 배경 AI · 원작자 추가 자료 내려받기
- 시스템 메뉴의 「버그 리포트」 자리에 「도구」(PC 메뉴줄의 도구 · 개발 목록)가 있습니다

### 알아 둘 것
- 디버그 키로 서명했습니다 — 새 판을 깔 때 옛 앱을 먼저 지워야 할 수 있습니다(세이브 · 설정은 원본 폴더 옆 자료 폴더에 있어 남습니다. 그 자리에 쓸 수 없어 앱 전용 폴더를 쓴 경우만 앱과 함께 지워집니다 — 첫 화면에 자료 폴더 자리가 나옵니다).
- 창세기전3 에 대한 모든 저작권은 라인게임즈에 있습니다. 팬 메이드 리메이크의 개인용 이식판입니다.

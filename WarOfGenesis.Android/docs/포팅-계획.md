## 정찰 (원본 v1.0.98, 2026-11-10)

- 원본(upstream): `Kyeongrok/the-war-of-genesis-clicker` — 포크 HEAD 가 원본 `v1.0.98` 과 같다.
- `WarOfGenesis.Assets`(net10.0, 약 1.2만 줄): 윈도우에 안 묶임. 윈도우 전용은 `AudioMixer.cs`, `WaveOutPlayer.cs`(winmm) 뿐.
- `duel-dx`(net10.0-windows, 약 7.4만 줄): CPU 로 `uint[]` 화면을 그린 뒤 D3D11 로 띄운다.
  - Vortice(D3D) 직접 사용: `GameWindow.cs`, `System/HiCanvas.cs`
  - WinForms: `System/BugReport.cs`, `System/MyBugReportsDialog.cs`, `System/OriginalGameSetup.cs`, `System/Part1TitleScreen.cs`
  - DllImport: `Program.cs`, `Win32.cs`, `Updater.cs`, `System/GamePad.cs`, `System/GamePad.Focus.cs`, `System/MediaFoundationAudio.cs`, `System/PlatformInfo.cs`, `System/BugReport.cs`, `System/MyBugReportsDialog.cs`
  - 영상/소리: `System/DirectShowVideo.cs`, `System/MediaFoundationAudio.cs` (Bink 해독기는 C# 이라 그대로 쓸 수 있을 듯)
  - ONNX DirectML: `Moses/HiResBackdrop.cs` · Velopack: `Updater.cs`
- 원본 자료: `OriginalGame.IsValid` = `TXR/Txr.dat` + `Chr/` + `Obs/`. 파트2 는 원본 파트2 폴더가 꼭 있어야 한다.
  파트1 만 있으면 `AssetDownload` 가 원작자 릴리즈(`assets-base-1` 등)에서 파트1 바탕 · 찾을 때 받는 것(그림 · 시디 곡 · 컷신)을 받는다.
- 화면 밖 시험 틀: `duel-dx/GameWindow.TestRun.cs` (`DUELDX_TESTRUN`, `DUELDX_AUTOPLAY`, `DUELDX_SNAPBURST`).

## 사용자 결정 (2026-11-10)

| 물음 | 결정 |
|---|---|
| 포팅 경로 | **(가) 소스 링크 포팅** — 원본 파일을 csproj 에서 링크, 원본은 안 고친다(꼭 필요하면 `#if ANDROID` 로 작게) |
| 뺄 기능 | **자동 업데이트(Velopack) · 버그 리포트/통계 전송 · 편집기(Editor) · 고해상도 배경 AI(ONNX DirectML)** — 넣지 않는다 |
| 남기는 것 | PC 파일 고르기 창은 빼지 않았다 → 원본 폴더 고르기 흐름은 안드로이드 방식(폴더 고르기)으로 살린다 |
| 파트 | **파트1 · 파트2 둘 다** (사용자 PC 에 원본 둘 다 있음) |
| 원작자 릴리즈 꾸러미(`AssetDownload`) | **PC 에서 만드는 zip 에 함께 넣는다** — 폰에서 인터넷으로 받지 않는다 |
| 대상 기기 | **레트로이드 같은 휴대 게임기** |
| 화면 비율 | 원본 비율 유지 + **설정에서 4:3 / 16:9 고르기** |
| 입력 | **터치가 기본**(누르기 = 클릭). 꼭 필요할 때만 화면에 **단축 아이콘**. **패드를 연결하면 패드 버튼을 키보드 · 마우스로 매핑** |
| 작업 브랜치 | `claude/elegant-knuth-45ndk5` (이 방에 정해진 것) |
| 앱 버전 / 태그 | **0.1.0 부터**, 릴리즈 태그 `android-v0.1.0` (꼭 `android-` 를 붙인다 — 원작자 `v*` 태그는 PC 판을 굽는다) |

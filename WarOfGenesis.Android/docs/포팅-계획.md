## 시험용 원본 자료 (2026-11-11)

- 원본 크기(사용자 PC): 파트1 약 1.4GB(압축 약 800MB) · 파트2 약 1.9GB(압축 약 1.4GB).
- 이 공개 포크는 그대로 공개로 둔다(포크는 비공개로 못 바꾸고, 공개 저장소의 Actions 는 무료 · 무제한).
- 시험용 자료는 **따로 만든 비공개 저장소의 릴리즈**에 zip 으로 붙인다(파일 하나 2GB 까지 — 파트별 1개씩이면 된다).
  원작자 릴리즈 꾸러미(`AssetDownload` 대상)도 같은 zip 에 넣는다. 공개 저장소 · 공개 릴리즈에는 절대 넣지 않는다.
- 세션이 비공개 릴리즈를 받을 수 있는지는 실제로 해 보고 확인한다(안 되면 PC 폴더 원격 연결로 바꾼다).

### zip 만들기 (`pc-script/`)

- PC 에서 `pc-script/자료-zip-만들기.bat` 을 두 번 누른다 → 파트1 · 파트2 폴더를 고른다 → 바탕화면 `창세기전-안드로이드-자료/` 에 zip 이 생긴다.
- zip 안의 자리: `part1/…`(파트1 폴더 전체) · `part2/…`(파트2 폴더 전체) · `assets/…`(원작자 pack.json 의 tier 90 이상 = 찾을 때 받는 것, 약 682개 · 800MB).
  앱 · 시험기는 이 셋을 한 폴더에 풀어 쓴다.
- 원본 폴더에서는 `.exe .dll .ocx .sys .msi .com .scr` 만 뺀다 — 리메이크 코드는 이것들을 읽지 않는다(2026-11-11 확인).
  게임이 여는 폴더가 넓어서(`OriginalGame.Locate` 의 `data/<폴더>` 등) 파일을 골라 담지 않고 폴더 전체를 담는다.
- zip 하나는 1.9GB 를 넘지 않게 `-01`, `-02` … 로 나눈다(파일 하나를 쪼개지는 않는다).
- 리눅스 pwsh 7.6 으로 가짜 폴더 · 원작자 자료 3개로 시험함. 윈도우 PowerShell 5.1 실제 실행은 사용자 PC 에서 확인할 것.

## 폰에서 원본 자리 (사용자 결정 2026-11-12)

- 레트로이드 내장 저장소가 9GB 남짓이라 **원본은 SD카드 등 아무 데나 두고, 앱에서 폴더나 zip 을 고른다** — 고른 자리에서 그대로 읽는다(복사 안 함).
- 고르기 화면 = PC 판 `OriginalGameSetup`(파트2 · 파트1 폴더 고르기 · 끝내기)의 안드로이드 판 + zip 고르기. `Game/GameSetup.cs`.
- zip: 원본 폴더를 누른 zip · `pc-script` zip 모두 된다 — 맨 위가 폴더 하나면 zip 옆에 그대로, 아니면 zip 이름 폴더에 푼 뒤
  `TXR\Txr.dat`(파트2) · `Obss\Obss.idx`(파트1)가 든 폴더를 찾는다. `assets/` 뿐인 zip(extras)은 게임 자료 폴더에 푼다.
- 게임 자료 · 세이브 폴더(PC 판 `%APPDATA%\DuelDx`) = 원본 폴더를 둔 폴더 옆 `WarOfGenesis-data`. 못 쓰면 그 저장소의 앱 전용 폴더 → 내장 앱 폴더.
- 원본 코드에는 환경 변수로 건넨다: `WAROFGENESIS_ORIGINAL`(파트2) · `WAROFGENESIS_PART1` · `DUELDX_SAVEDIR` — 원본 코드를 안 고친다.
- 처음 판(0.1.0 시험판)의 `WarOfGenesis` 내장 폴더 방식은 버렸다.
- **사용자 기기 확인(2026-11-12, run 43160220945 APK)**: SD카드 `/storage/4A5C-81C4/emull/Genesis3/` 의 part2 폴더를 고르자 옆 part1 도 찾음.
  `WarOfGenesis-data` 쓰기 됨(SD카드에 쓸 수 있다). extras-01.zip 803MB 풀기 됨(682개). 파트2 이름표 2772줄 · 파트1 인물 이름 한글로 읽음.
  SD카드 읽기 초당 28~33MB.

## 원본 병합 점검 (원본 업데이트를 받을 때마다)

1. `git fetch upstream main --tags` → 새 `v*` 태그를 병합.
2. **새 윈도우 호출이 생겼나**: `git diff <옛 태그> <새 태그> -- '*.cs' | grep -E 'DllImport|LibraryImport'` —
   iOS 판이 원본 v1.0.72 의 `SetThreadExecutionState` · `GetDpiForWindow` 로 시작하자마자 죽었다(docs/iOS-포팅-참고.md i2).
3. 새 파일 · 갈아 끼운 파일의 원본이 바뀌었나 확인 → 안드로이드 APK 를 다시 굽는다.
4. iOS 포팅(sonicusers/twgios) 릴리즈노트도 본다 — 같은 PC 판 코드를 모바일에서 돌리므로 같은 문제가 난다.

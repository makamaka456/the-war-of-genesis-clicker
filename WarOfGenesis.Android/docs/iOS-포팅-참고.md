# iOS 포팅(sonicusers/twgios)에서 배운 것

확인: 2026-11-12 · 2026-11-13(새 커밋 없음), twgios 최신 커밋 2026-11-09(iOS 판 1.1.6).
**라이선스 파일이 없다 → 코드는 한 줄도 가져오지 않고 방식만 참고한다**(대원칙 §3).

## 그 저장소는 무엇인가

- 소스 링크가 아니라 **런처 + 실행 중 패치** 방식이다: 원작자 릴리즈 dll(`WarOfGenesis.dll`, `WarOfGenesis.Assets.dll`)을 폰에서
  받아 `WogPatcher.dll`(Mono.Cecil 로 IL 고치기)로 고치고, `WogShim.dll`(WinForms · Win32 대용품)에 얹어 돌린다.
- README: 「APK 의 WogShim / WogPatcher 를 그대로 쓰고, 안드로이드 전용 부분(WogAndroid)만 iOS 용으로 새로 쓴 것」 —
  즉 **이미 안드로이드 APK 가 있다**(네이버 창세기전 카페 「실벤트」님 작, 릴리즈노트 1.0.6). 그 APK 의 소스는 이 저장소에 없다.
- 우리는 (가) 소스 링크 포팅이라 길은 다르지만, **같은 PC 판 코드를 모바일에서 돌리므로 같은 문제가 난다.**

## 입력 설계에 참고할 것 (방식만)

- 터치: 탭 = 클릭, 끌기 = 끌기, 길게 = 우클릭, 두 손가락 = 휠 · 우클릭. 목록 화면(캐릭터 · 군단 에디터, 아이템 · 스킬 보기)에서는 한 손가락 끌기를 휠로.
- 패드: 게임은 XInput 을 읽는다(`duel-dx/System/GamePad.cs`) → 안드로이드 패드 입력을 그 자리에 넣는다.
- 단축 아이콘: 키보드 단축키를 보내는 버튼. 글 입력이 필요한 곳(에디터 · 검색)은 안드로이드 키보드 → WM_CHAR 에 해당하는 길.
- 배속 버튼: 게임 설정의 「게임 속도」와 같은 값(`GameWindow.SpeedChoices` = 100 · 150 · 200, 메뉴 명령 1110 + 순번)을 쓴다 — 새 값을 지어내지 않는다.

## 참고만 하고 안 하는 것

- 자동 업데이트 · 이전 버전 고르기 · 시작 실패 시 옛 판으로 (우리는 소스 링크라 APK 를 다시 굽는다. 자동 업데이트는 뺀 기능)
- 버그 리포트 iOS 창 (뺀 기능)
- 안내줄 버튼 아이콘 모양 바꾸기 · 시작 일러스트 (원본에 없는 UI — 사용자가 원하면 따로 묻는다)
